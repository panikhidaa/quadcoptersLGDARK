# Магазин квадрокоптеров и экшн-камер — ДНР / ЛНР

Статический интернет-магазин для продажи квадрокоптеров, экшн-камер, запчастей и аксессуаров с фокусом на Донецк, Луганск и регионы Донбасса.

## Структура

```
drone-shop/
├── index.html                 # Главная (Донецк + Луганск, общая)
├── donetsk.html               # Городской лендинг: Купить квадрокоптер в Донецке
├── lugansk.html               # Городской лендинг: Купить квадрокоптер в Луганске
├── catalog/
│   ├── index.html             # Каталог категорий
│   ├── kvadrokoptery-dji.html # Квадрокоптеры DJI
│   ├── zapchasti.html         # Запчасти DJI
│   ├── ekshn-kamery.html      # Экшн-камеры (GoPro, Insta360, DJI Osmo)
│   ├── aksessuary.html        # Аксессуары
│   ├── akkumulyatory.html     # Аккумуляторы
│   ├── fpv.html               # FPV-дроны
│   └── remont.html            # Ремонт DJI
├── cart.html                  # Корзина
├── checkout.html              # Оформление заказа
├── delivery.html              # Доставка по ДНР/ЛНР (Почта Донбасса, Почта ЛНР)
├── payment.html               # Оплата (ПСБ, СБП, наличные)
├── warranty.html              # Гарантия и возврат
├── contacts.html              # Контакты (два адреса + два телефона)
├── about.html                 # О магазине
├── 404.html                   # Страница 404
├── assets/
│   ├── css/styles.css
│   ├── js/main.js             # Корзина, поиск, навигация
│   └── img/favicon.svg
├── sitemap.xml                # Карта сайта для Яндекса/Google
├── robots.txt                 # Директивы для роботов + Clean-param
├── feed.yml                   # Шаблон фида для Яндекс.Товаров
└── manifest.webmanifest       # PWA-манифест
```

## Локальный запуск

```bash
cd drone-shop
python -m http.server 8080
```

Откройте http://localhost:8080.

## Что нужно сделать перед публикацией

1. **Заменить телефоны** в файлах на реальные. В коде сейчас:
   - ДНР: `+7 (959) 777-45-45` / `+79597774545`
   - ЛНР: `+7 (959) 777-45-45` / `+79597774545`

2. **Заменить адреса**. Сейчас в коде:
   - Донецк, ул. Артёма, д. 1
   - Луганск, ул. Советская, д. 1

3. **Заменить координаты** (`geo.position`, `ICBM`, `latitude`/`longitude` в JSON-LD) на реальные координаты вашего магазина.

4. **Заменить домен** `example.ru` на ваш — в `<link rel="canonical">`, `og:url`, sitemap.xml, robots.txt, feed.yml.

5. **Загрузить логотип** в `assets/img/` (рекомендуется `og.jpg` 1200×630 для Open Graph и `logo.svg` для шапки).

6. **Заполнить товары**. Сейчас в категориях стоит плейсхолдер «тут будут ваши товары».

## План SEO-вывода в ТОП Яндекса по «квадрокоптеры Донецк / Луганск»

### Шаг 1. Яндекс.Вебмастер (1-й день)

1. Зарегистрируйтесь: https://webmaster.yandex.ru
2. Добавьте свой сайт (после хостинга).
3. Подтвердите права — через мета-тег `<meta name="yandex-verification" ...>` (вставьте в `<head>` всех страниц) или через HTML-файл в корне.
4. **Настройки → Региональность → Указать вручную:**
   - Регион: **Донецк** (или Луганск — выберите где физический склад).
   - Сошлитесь на страницу `/donetsk.html` (или `/lugansk.html`).
5. Залейте `sitemap.xml`: https://example.ru/sitemap.xml
6. Проверьте `robots.txt` через инструмент «Анализ robots.txt».
7. Отправьте на переобход главные страницы: главную, /donetsk.html, /lugansk.html, /catalog/kvadrokoptery-dji.html.

### Шаг 2. Яндекс.Бизнес — карта (1-й день, КРИТИЧНО)

> **Это поднимает сайт в ТОП локальной выдачи Яндекса автоматически.**

1. https://business.yandex.ru → «Добавить организацию».
2. Заполните карточку **для Донецка**:
   - Название: ваше название магазина.
   - Адрес: реальный (ул. Артёма, д. 1 — пример).
   - Категория: **«Магазин электроники»** + **«Квадрокоптеры и дроны»** + **«Сервисный центр»**.
   - Телефон: `+7 949 …` (мобильный код ДНР).
   - Сайт: ваш домен.
   - Часы работы: Пн–Сб 9:00–19:00.
3. **Подтверждение прав:**
   - SMS-кодом на телефон с кодом `+7 949` (для ДНР) или `+7 959` (для ЛНР).
   - Если SMS не приходит — заявка с фото фасада/вывески, выписка по адресу. Яндекс верифицирует Донецк и Луганск.
4. Загрузите **5–10 качественных фото** офиса/витрины/товаров.
5. Аналогично создайте карточку **для Луганска** (отдельная организация на тот же сайт).
6. После верификации добавьте на сайт виджет карт — на странице `contacts.html` уже есть место для виджета.

### Шаг 3. Контент и текстовая оптимизация (1-я неделя)

✅ **Уже сделано в коде:**
- Title формата «Купить [товар] в Донецке/Луганске» для главной и всех категорий.
- Description с упоминанием городов и формулой «Гарантия, быстрая доставка по ЛНР и ДНР».
- На главной — упоминание Донецка, Луганска, Макеевки, Горловки, Алчевска, Мариуполя, Стаханова.
- Городские лендинги `/donetsk.html` и `/lugansk.html` — заточены под прямые запросы «квадрокоптер Донецк» и «квадрокоптер Луганск».
- JSON-LD `LocalBusiness` × 2 (для Донецка и Луганска) на `contacts.html`.
- Подробная страница `/delivery.html` с Почтой Донбасса, Почтой ЛНР, складом в Ростове.
- Страница `/payment.html` с акцентом на карты ПСБ и СБП.

**Что нужно дополнить когда появятся товары:**
- Для каждого товара формируйте title по формуле: `Купить [Модель] в Донецке — цена [N] ₽ | Магазин`.
- В описание товара добавляйте: «Доставка по Донецку и Луганску за 1–2 дня. Гарантия. Оплата ПСБ или наличными.»
- На карточках товара ставьте микроразметку `Product` (Schema.org).

### Шаг 4. Яндекс.Товары (бесплатная товарная галерея, 1-я неделя)

1. В Яндекс.Вебмастере → раздел **«Товары»**.
2. Подключите фид — у нас уже готов шаблон `feed.yml` (по адресу `https://example.ru/feed.yml`).
3. Заполните `feed.yml` своими товарами (структура внутри файла, с примерами).
4. Карточки появятся в товарной галерее Яндекса бесплатно. Это очень мощный канал для коммерческих запросов.

### Шаг 5. Яндекс.Директ (контекстная реклама, 1-я неделя)

> **Цель:** быстрые продажи + улучшение поведенческих факторов сайта.

**Важный нюанс 2026 года:** при настройке геотаргетинга для новых регионов в стандартных списках Директа может не быть полноценного выбора областей.

**Единственный рабочий способ:**

1. Создайте кампанию через **«Мастер кампаний»**.
2. В блоке геотаргетинга выберите **«Указать регион на карте»**.
3. Вручную поставьте точки на:
   - Донецк (радиус 10–15 км)
   - Луганск (радиус 10 км)
   - Макеевка (5 км)
   - Горловка (5 км)
   - Алчевск (5 км)
   - Стаханов (5 км)
   - Мариуполь (10 км) — если возите туда
4. Начните с 3–5 кампаний:
   - «Купить квадрокоптер DJI» (горячие коммерческие запросы)
   - «Запчасти для DJI» (узкая ЦА)
   - «Экшн-камеры GoPro/Insta360»
   - «Ремонт DJI» (сервисные запросы)
   - Бренд + город: «DJI Mavic Донецк»
5. Бюджет на старт: 1000–2000 ₽/день на каждую кампанию. Через 2 недели смотрите CR и масштабируйте.

### Шаг 6. Внешние сигналы (2–4 недели)

- Карточка в **2ГИС** для Донецка и Луганска.
- Отзывы на Яндекс.Картах (первые — попросить у клиентов).
- Каталоги: Otzovik, IRecommend, локальные форумы Донбасса.
- Социальные сети: VK, Telegram-канал с обзорами.
- Партнёрство с местными сервисами/магазинами (взаимные ссылки).

### Шаг 7. Поведенческие факторы (постоянно)

- Сделайте быструю загрузку (уже < 1 сек, потому что статика).
- Удобный поиск, чёткие категории.
- Подробные карточки товаров (фото, видео, отзывы).
- Чат-бот в WhatsApp/Telegram — отвечайте быстро.
